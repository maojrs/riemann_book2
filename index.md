This book illustrates the solution of Riemann problems for hyperbolic partial differential
equations, and the approximate Riemann solvers used in finite volume methods, through
interactive Jupyter notebooks.

Parts I and II are published by SIAM as a print book and an ebook:

> D. I. Ketcheson, R. J. LeVeque and M. J. del Razo,
> [*Riemann Problems and Jupyter Solutions: Theory and Approximate Solvers for Hyperbolic
> PDEs*](https://epubs.siam.org/doi/book/10.1137/1.9781611976212), SIAM, 2020.
> ISBN 978-1-611976-20-5.

The chapters under *Further topics* are additional notebooks on more advanced topics and
additional hyperbolic systems.

## About this web edition

This new release makes the book available as a web edition. Its text, 
scientific content, and underlying scientific code—including the exact 
Riemann solvers and numerical methods—remain unchanged from the original 
edition. The plotting routines and interactive figures, however, have 
been partially rewritten and optimized to run smoothly and efficiently 
in a web browser.

- **Interactive figures in your browser.** The book's own Python code runs in your web browser,
  with no installation, server or account. The plotting was rewritten so that the figures
  respond quickly as you move the sliders.
- **Pure Python.** The finite-volume computations originally performed using Clawpack in the 
notebooks have been reimplemented in a lightweight Python package called miniclaw. It includes 
only the algorithms needed for the book and is not intended to replace Clawpack, which offers 
much broader functionality.
- **Tested.** A test suite checks the science: exact solutions, jump and entropy conditions,
  conservation, convergence, and agreement with the original book's results.

The original notebooks are available at
[github.com/clawpack/riemann_book](https://github.com/clawpack/riemann_book), and the changes
made in this edition are listed in
[CHANGES.md](https://github.com/maojrs/riemann_book2/blob/main/CHANGES.md).

### How to use this book

**The interactive figures.** When a chapter opens, Python starts in the background. The first
time, your browser downloads about 20 MB (it keeps them for later visits), and starting takes a
few seconds. Until Python is ready, each figure shows a still picture with the line *Starting Python 
in your browser…*; the controls appear when it is ready. Each chapter starts its own Python, so 
opening another chapter takes a few seconds again.

- Move the sliders, tick the boxes or choose from the menus, and the figure is drawn again.
- Some figures can be explored by dragging points, such as the left and right states in a
  phase plane, or the time in the $x$-$t$ plane.
- Animations have their own controls to play, pause and step through the frames.
- The figures also work on phones and tablets, more slowly.

If a figure does not respond, wait until its controls appear, or reload the page. If a figure
cannot be drawn for the values you chose, it says so; choose other values.

**Running the code yourself.** The code cells in each chapter correspond to those in its 
Jupyter notebook, and the figures are generated by running that code. Although the web 
version uses some plotting optimizations, the underlying code is essentially the same. 
You can therefore run and modify it directly in the notebooks. To get started:

- **Remotely:** the rocket icon at the top right of a chapter opens it on
  [Binder](https://mybinder.org) in JupyterLab (a few minutes to load). Binder
  does not keep your changes: to keep a notebook, download it.
- **Locally:** [download the notebooks](https://github.com/maojrs/riemann_book2/releases/latest/download/riemann_book_notebooks.zip)
  and unpack the archive. Then, from the unpacked folder, install the book's code 
  and JupyterLab, and open the chapter notebooks to run and explore the code yourself.

  ```bash
  pip install -e . jupyterlab
  jupyter lab chapters/
  ```
